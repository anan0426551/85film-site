## 压缩要求（重要）
- GitHub 单文件上限 **100MB**，超过会被拒绝推送；整个网站建议控制在 **1GB 以内**
- 建议每条视频压缩到 **10~50MB**（1080P / H.264 / 码率 2~4Mbps 即可）
- 可用「剪映导出」或 HandBrake 压缩
